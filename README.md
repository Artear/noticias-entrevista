# Últimas noticias

App chica en React que lista notas de un portal de noticias. Se puede filtrar por categoría, buscar por título, ordenar por más leídas y marcar notas como guardadas.

## Cómo correrla

```bash
npm install
npm run dev
```

## Contexto

- `src/api.js` simula el backend. No hace falta modificarlo.
- El resto del código lo escribió otra persona del equipo y nos llegaron reportes de que algunas cosas no funcionan como deberían.
